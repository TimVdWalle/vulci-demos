# Vulci Demo Programs

Small, runnable programs that demonstrate Vulci through complete examples rather
than isolated syntax snippets.

## Requirements

Install Vulci `v0.15.0` or newer. The reference interpreter and installation
instructions are available in the
[Vulci language repository](https://github.com/TimVdWalle/vulci-language).

## Demo index

| ID | Demo | Description | Language phase     |
| --- | --- | --- |--------------------|
| `demo-logicviz` | [LogicViz](logicviz/README.md) | Visualizes and evaluates three Boolean logic circuits in the terminal. | Phase 15  (0.15.0) |

## Run a demo

Run a demo entry file from the repository root:

```shell
vulci logicviz/main.vci
```

Each demo directory contains its own README with its requirements, structure,
and usage.
